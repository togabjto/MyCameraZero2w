# Web アプリ（`src/webapp.py`）

設置したカメラを、SSH で起動して放置し、**ブラウザから**操作するための常駐アプリ。

- 監視の開始・停止
- ライブ映像（320x240・白黒。検知用の映像）と、「録画中」の表示
- 録画の一覧・再生（再生・一時停止・10 秒とばし・倍速）
- 稼働状況、録画の件数、ディスクの空き、ログの表示

## 使い方（Pi 上で）

```
cd ~/MyCameraZero2w
make -C src
tmux                                                    # SSH が切れても止まらないように
TOOLS_PASSWORD=好きな文字列 python3 src/webapp.py --autostart
# Ctrl+B → D で tmux から抜けて、SSH を切ってよい（戻るときは tmux attach）
```

同じ LAN のブラウザで `http://<Pi の IP>:8000/` を開く（ユーザー名: `admin`）。

| 画面 | 内容 |
|---|---|
| `/`（ホーム） | 状態、開始・停止ボタン、ライブ映像、ディスクの空き、ログ |
| `/recordings` | 録画の一覧。クリックで再生 |

主なオプション:

| オプション | 内容 |
|---|---|
| `--autostart` | Web アプリの起動と同時に、監視も開始する |
| `--workdir DIR` | 録画（`DIR/movie/`）とログ（`DIR/logs/`）の場所。既定は、今いるフォルダ |
| `--port N` | Web アプリのポート。既定: 8000 |
| `--pixel-threshold`, `--change-ratio` | 監視の感度（`surveillance.py` と同じ） |

## 仕組み

- Web アプリが、`surveillance.py` を**子プロセス**として起動・停止する。
- 停止は Ctrl+C と同じ信号（SIGINT）。**録画中に止めると、MP4 に保存してから終わる**（最大 30 秒待ち、それでも終わらなければ強制終了）。
- ライブ映像は、子プロセスが `127.0.0.1` だけで配信し、Web アプリが中継する。LAN には直接出ない。
- パスワードは、子プロセスにコマンドライン引数ではなく、環境変数で渡す（`ps` に出ない）。
- Web アプリを止める（Ctrl+C や `kill`）と、子の監視も止まる。

## 注意

- **パスワード必須。通信は HTTP（暗号化されない）なので、LAN の中だけで使う。ルーターのポート開放はしない。**
- 開始・停止の操作は、別のサイトから勝手に実行されないよう、画面の `fetch` だけが付けるヘッダーと `Origin` を確認している。
- **このアプリが起動した監視だけを管理する。** 別に `surveillance.py` を動かしていると、カメラが使えず、失敗する（ログに出る）。
- **録画の自動削除はない。** ホームのディスク空きを、ときどき確認する（使用率が 90% 以上で警告が出る）。
- **監視が異常終了しても、自動では再起動しない。** ホームの状態が「停止」になり、前回の終了コードが出るので、ボタンで再開する。
- Pi の電源を入れ直すと、Web アプリも止まる（起動時の自動実行は未設定）。
- 録画の保存先が、今までの `src/movie/` と違う場合は、`--workdir src` を指定するか、ファイルを移す。
